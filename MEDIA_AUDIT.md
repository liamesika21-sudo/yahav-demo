The original source folders under `src/yahav` remain untouched. The published site uses a deliberately smaller derivative library under `public/media`, generated by `scripts/process-media.sh`.

The audit considered pixel dimensions, orientation, aspect ratio, file size, sharpness, crop suitability, color consistency, repetition and whether each photograph represented a complete space or a detail. Contact sheets were used to compare every asset within its own project.

## Notable exclusions

- `IMG_4925.HEIC` and `IMG_4925(1).HEIC` in the clinic folder are byte-identical; neither duplicate was needed in the finished gallery.
- Before/construction photographs were not paired with unrelated finished images, so no before/after claims are published.
- The Herzliya source has no verified finished photography. It is omitted from the homepage's completed-project selection and labelled `תיעוד תהליך` in the archive/detail view.
- ChatGPT/Gemini-named images are not used as project evidence or homepage hero photography.
- No original local version of the Facebook film was present. The site uses a local lightweight poster and creates the third-party iframe only after Play.

## Delivery format

- Each chosen still has 960px and 1800px WebP derivatives with source aspect ratio preserved.
- Below-fold images use native lazy loading; dimensions and aspect ratios prevent layout shift.
- The first hero image is high-priority. Later hero images are introduced progressively.
- The optimized published media set is approximately 8.8 MB; original HEIC/JPG/MOV files are never served directly.
